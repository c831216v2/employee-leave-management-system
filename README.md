# Employee Leave Management System

🔗 **Live Demo:** https://employee-leave-management-system-6cif.onrender.com/

A web-based Employee Leave Management System that streamlines leave requests, approvals, leave balance tracking, and reporting through an intuitive and user-friendly interface.

## 🚀 Features

- Employee leave request submission
- Manager approval and rejection workflows
- Leave balance tracking
- Leave history and reporting
- Secure authentication and authorization
- Responsive and user-friendly interface
